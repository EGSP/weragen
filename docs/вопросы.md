# Вопросы о weragen

Ответы описывают замысел продукта.

## Продуктовая концепция

1. Для кого weragen в первую очередь?

   Для разработчиков и команд, которые внедряют ИИ в процессы предприятия. weragen разворачивается внутри организации и служит единой точкой обращения к ИИ для её систем и программ.

2. Какую задачу этот человек решает сейчас и чем пользуется вместо weragen?

   Разработчик создаёт и сопровождает автоматизации бизнес-процессов с участием ИИ. Сейчас отдельные программы и сервисы самостоятельно обращаются к моделям, хранят контекст и ведут историю работы. Чтобы понять состояние процесса и действия агентов, приходится собирать сведения из разных мест. Вместо weragen используют собственный набор программ и настроек, библиотеки для агентов либо платформы, которые не отвечают требованиям к размещению и автоматизации процессов.

3. Какой один сценарий использования weragen можно показать работающим от начала до конца?

   «Советник оператора». Сервис отображает графики и ленту событий и обращается к weragen за анализом технологического процесса. Оркестратор запускает агентов, которые исследуют данные с помощью инструментов, а затем возвращает заключение в формате JSON, заданном вызывающим сервисом. Оператор видит совет; разработчик может просмотреть ход работы агентов и всего сценария.

## Ценностное предложение

1. Какой результат пользователь получает с weragen?

   Разработчик создаёт и сопровождает ИИ-автоматизации, используя общую платформу для работы с моделями, агентами и воркфлоу. Программы с предметной логикой остаются самостоятельными. Состояние процесса, действия агентов и работа внешних исполнителей видны в одном месте.

2. Почему для этого результата он выберет именно weragen?

   weragen можно разместить в инфраструктуре организации и использовать как единую точку работы с языковыми моделями, агентами и воркфлоу. Разработчик пишет программы с предметной логикой на подходящем языке, не встраивая их в код платформы. SDK позволяют этим программам передавать сведения о ходе работы в общий журнал и систему трассировки. Для организаций, которым трудно закупать зарубежные решения, самостоятельное размещение делает такой подход доступнее.
